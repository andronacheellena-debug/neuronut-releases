# Neuronuț — canalul de actualizări și licențe
- `neuronut-motor.zip` — motorul curent (nume stabil; update-ul îl descarcă de aici)
- `versiune.json` — versiunea curentă + notele pentru om
- `licente.json` — amprentele (sha256) adreselor Claude cu licență; fără e-mailuri în clar
- `sync_licente.py` — construiește licente.json dintr-o listă de e-mailuri (lista nu se urcă niciodată aici)
